# Diseño

| Carpeta | Contenido |
|---|---|
| `canvas/` | Código fuente de las 11 pantallas del lienzo y `canvas.json`. Índice en `docs/06-pantallas.md`. |
| `tokens/` | `tokens.json` (para código o Figma Tokens) y `tokens.css` (variables CSS listas para usar). |
| `assets/` | SVG del glim en sus 8 estados (`glim-<estado>.svg`), icono de app (`glimo-icon.svg`), `favicon.svg` y logotipo (`glimo-logo.svg`, `glimo-logo-on-ultramar.svg`, con el texto convertido a trazos). |

Lienzo en vivo: https://claude.ai/artifact/1uxMU24XS7LboqoeDiaPvu

Los archivos `.dc.html` usan el formato del lienzo y no abren tal cual en un navegador: úsalos como referencia exacta de estructura, textos, colores y tamaños.
